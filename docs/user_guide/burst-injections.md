# Burst injections

A **burst** is a short gravitational-wave transient with no reliable template:
core-collapse supernovae, and anything else an unmodelled search is meant to
find. Searches for them are characterised by injecting a set of simple **ad
hoc** morphologies spanning the band and durations of interest, plus
**numerical** waveforms from simulations where they exist.

This page is both the user guide for `BurstSimulator` and the **specification of
the burst test injection set** it produces.

!!! warning "Status: draft"

    The injection set below is a draft. It follows the first Einstein
    Telescope mock data challenge (MDC-1) wherever MDC-1 made a choice, and
    the LVK O3 all-sky short-burst search where MDC-1 made none; every row and
    its source are in [Relation to MDC-1](#relation-to-mdc-1). The values
    marked *open* in [Open items](#open-items) still need to be agreed for a
    given data set before an injection campaign is generated from it.

!!! tip "API reference"

    Signatures, types and raised exceptions are in the
    **[Burst API](../api/burst/)**.

## Quick example

```python
import numpy as np

from gwmock_signal import resolve_simulator_backend
from gwmock_signal.burst import draw_burst_injection_set

events = draw_burst_injection_set(
    start_time=1_000_000_000.0,
    end_time=1_000_086_400.0,  # one day
    interval=300.0,  # one injection every 300 s
    hrss_range=(1e-23, 1e-20),  # must straddle the network's threshold
    rng=np.random.default_rng(2026),
)

simulator = resolve_simulator_backend("burst")()
for event in events:
    strain = simulator.simulate(
        event,
        ["E1", "E2", "E3"],
        sampling_frequency=8192.0,
        minimum_frequency=5.0,
    )
```

`simulate` returns a `DetectorStrainStack` exactly as the compact-binary
simulator does, and accepts the same optional `background` mapping to inject
into existing data.

## Specification

### Event record

Each injection is one mapping. The keys correspond to the per-event record of
established burst injection pipelines — peak time, distance, sky position,
polarization angle, inclination and model — under this package's canonical
names, so a burst injection follows the same route as any other transient:
polarizations, then projection onto each detector, then injection.

| Key                  | Meaning                                                                       | Used by         |
| -------------------- | ----------------------------------------------------------------------------- | --------------- |
| `burst_model`        | morphology: `sine_gaussian`, `gaussian`, `white_noise_burst`, or a file model | all             |
| `peak_time`          | GPS time of the waveform's centre at the geocentre, s                         | all             |
| `right_ascension`    | rad                                                                           | all             |
| `declination`        | rad                                                                           | all             |
| `polarization_angle` | rad                                                                           | all             |
| `hrss`               | $\sqrt{\int (h_+^2 + h_\times^2)\,dt}$ at the Earth                           | ad hoc families |
| `inclination`        | rad; sets the polarization ellipse, or the file waveform's angular factor     | SG, WNB, files  |
| `frequency`          | central frequency $f_0$, Hz                                                   | SG              |
| `quality_factor`     | $Q$                                                                           | SG              |
| `duration`           | GA: standard deviation $\tau$ of $h_+(t)$; WNB: time envelope, s              | GA, WNB         |
| `low_frequency`      | lower edge of the band, Hz                                                    | WNB             |
| `bandwidth`          | width of the band, Hz                                                         | WNB             |
| `seed`               | integer fixing the noise realisation                                          | WNB             |
| `distance`           | source distance, Mpc                                                          | file models     |
| `injection_set`      | `"test"` for every event of the test set                                      | label, not used |

Keys a model does not use are ignored, which is what lets an event carry a
label.

### Waveform families

The ad hoc waveforms are generated by LALSimulation's burst routines, the ones
the LVK burst injections use, so their shapes are LAL's. Every family is then
scaled so that its samples carry the requested `hrss`, which corrects a pulse
narrower than the sample spacing and changes a well-sampled one by about
$10^{-16}$.

| Family                  | Draft parameters                                                                                                                            | Polarization                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Sine-Gaussian (SG)      | $Q = 3, 9, 100$; $f_0$ log-uniform in 30–1800 Hz                                                                                            | elliptical, uniform in $\cos\iota$                                  |
| Gaussian pulse (GA)     | $\tau = 0.1$ ms, $2.5$ ms                                                                                                                   | linear                                                              |
| White-noise burst (WNB) | $(f_\text{low}, \Delta f, \tau) = (100, 100, 0.1), (250, 100, 0.1), (700, 100, 0.1)$ (Hz, Hz, s); O3 quotes the third by its centre, 750 Hz | elliptical, uniform in $\cos\iota$; one noise realisation per event |
| Numerical (e.g. CCSN)   | supplied as files; see [Numerical waveforms](#numerical-waveforms)                                                                          | as in the file                                                      |

The Gaussian durations and white-noise parameters are those of the O3 all-sky
search (Phys. Rev. D **104**, 122004, Table I). The sine-Gaussians are this
set's own choice, not O3's. O3's Table I lists circular sine-Gaussians at fixed
pairs of $Q = 3$, $8.9$, $9$ and $100$ and central frequencies from 70 Hz to
3067 Hz; O3 also injected an elliptical set, uniform in $\cos\iota$, alongside
the circular one at optimal orientation (§IV A). This set keeps $Q = 3$, $9$ and
$100$, elliptical only (uniform in $\cos\iota$), and draws the central frequency
log-uniformly over 30–1800 Hz instead of using O3's grid, which keeps every
$f_0$ far below the 4096 Hz Nyquist frequency of 8192 Hz data.
`DRAFT_BURST_FAMILIES` holds this table.

A source at inclination $\iota$ radiates $h_\times / h_+ = 2\cos\iota / (1 +
\cos^2\iota)$: circular when face-on, linear when edge-on. A circularly
polarized family, as O3 also used, is obtained by fixing `inclination` to `0` in
the family.

### Strength

`hrss` is drawn **log-uniform** over a range that must **straddle the detection
threshold** of the network under test, so that the efficiency curve is sampled
from where nothing is found to where everything is. The range has no default
because it depends on the detectors and the noise.

### Rate and placement

Injections are placed at a **fixed rate**, one per `interval` seconds, at
`start_time + (k + 1/2) * interval`. A spacing of a few hundred seconds keeps
the signals well separated — the longest draft waveform lasts about a second —
so each injection is recovered or missed on its own. Sky positions are
**isotropic** (uniform in right ascension and $\sin\delta$), and polarization
angles uniform in $[0, \pi)$.

### Choosing the strength range and the interval

Both are inputs to `draw_burst_injection_set`, with no default, because they
depend on the detector network. The LVK searches give a convention to follow:

- **Interval.** The O2 all-sky short-duration search injected one event every 50
  s, with a uniform jitter of ±5 s [O2, Sect. III.C]. 50 s is far longer than
  any family here (the longest, a `Q = 100` sine-Gaussian at 30 Hz, has an
  envelope of about 0.75 s), so the events do not overlap. This draw places
  events on a fixed grid without the jitter.
- **Strength.** The O3 search injected each family on the grid $h_\mathrm{rss} =
  (\sqrt{3})^N \times 5 \times 10^{-23}\,\mathrm{Hz}^{-1/2}$, `N = 0, ..., 8`,
  and found 50% detection efficiency at $h_\mathrm{rss} \approx 0.8$–$2.4 \times
  10^{-22}$ for its circular sine-Gaussians from 70 Hz to 1.6 kHz, rising to
  $5.6 \times 10^{-22}$ at 3 kHz, and at $1.8$–$2.5 \times 10^{-21}$ for its
  Gaussian pulses [O3, Sect. IV, Table I], so the grid spans the thresholds from
  just below them to above them. For another network, scale the grid by the
  ratio of the networks' amplitude spectral densities in the band, which moves
  the threshold by the same factor and keeps its place in the range. For one 10
  km Einstein Telescope interferometer (`ET_10_full_cryo_psd`) against O3
  Livingston (`aLIGO_O3_actual_L1_psd`), both bundled with `gwmock-noise`, the
  ratio is close to 0.07 from 70 Hz to 1.8 kHz (median 0.072, with 97% of the
  frequency bins within 15% of it; the exceptions are narrow spectral lines,
  which are excluded), giving a log-uniform range of $3.5 \times 10^{-24}$ to
  $2.8 \times 10^{-22}$. The single-interferometer ratio ignores the differences
  in network geometry and antenna response.

[O2]: B. P. Abbott et al., "All-sky search for short gravitational-wave bursts
in the second Advanced LIGO and Advanced Virgo run", Phys. Rev. D 100, 024017
(2019), arXiv:1905.03457. [O3]: R. Abbott et al., "All-sky search for short
gravitational-wave bursts in the third Advanced LIGO and Advanced Virgo run",
Phys. Rev. D 104, 122004 (2021), arXiv:2107.03701.

### Test set, not population

The rate is chosen to measure a search's sensitivity, not drawn from any
astrophysical rate: a Galactic core-collapse rate would give essentially no
events in a month. Every event therefore carries `injection_set="test"`, and
results from it must not be read as an astrophysical population.

## Numerical waveforms

Numerical waveforms, such as core-collapse supernova simulations, are supplied
as text files with three whitespace-separated columns — time (s, relative to the
waveform's reference instant), $h_+$ and $h_\times$. Each file is described by a
`WaveformFile`: its path, the distance its strain is given at, and how that
strain depends on the viewing angle:

```python
from gwmock_signal.burst import BurstSimulator, WaveformFile

simulator = BurstSimulator(
    waveform_files={
        "model_a": WaveformFile(
            "waveforms/model_a.txt",
            reference_distance=0.01,  # Mpc, i.e. the file is at 10 kpc
            inclination_dependence="axisymmetric",
        ),
    }
)
event = {
    "burst_model": "model_a",
    "peak_time": 1_000_000_150.0,
    "distance": 0.005,  # 5 kpc
    "inclination": 1.2,
    "right_ascension": 1.0,
    "declination": -0.4,
    "polarization_angle": 0.3,
}
```

The file's time origin is placed at `peak_time`, the strain is scaled by
`reference_distance / distance` and by the angular factors below, and the
waveform is resampled to the requested rate if the file's differs.

| `inclination_dependence` | The file holds        | $h_+$ factor          | $h_\times$ factor |
| ------------------------ | --------------------- | --------------------- | ----------------- |
| `"none"` (default)       | one viewing direction | 1                     | 1                 |
| `"axisymmetric"`         | the edge-on strain    | $\sin^2\iota$         | 0                 |
| `"rotating"`             | the face-on strain    | $(1 + \cos^2\iota)/2$ | $\cos\iota$       |

`"axisymmetric"` is an $\ell = 2$, $m = 0$ quadrupole, which is linearly
polarized; `"rotating"` is an $\ell = 2$, $m = \pm 2$ pair, circular face-on and
linear edge-on. A waveform with several modes, or one given for a single
direction, is used as `"none"`; a set covering several directions is several
files.

**No numerical waveforms are distributed with this package.** The loader is the
interface; the waveform files themselves come from their authors.

## Conventions and what they are checked against

- **Normalisation.** `hrss` is checked by computing $\sqrt{\sum (h_+^2 +
  h_\times^2)\,\Delta t}$ directly, independently of LAL, for every family.
- **Polarization ellipse.** The ratio $h_\times/h_+$ is checked against
  $2\cos\iota / (1 + \cos^2\iota)$ across inclinations, and the handedness flips
  for $\iota > \pi/2$.
- **File inclination factors.** The `"axisymmetric"` and `"rotating"` factors
  are checked against the $\ell = 2$ spin-weighted spherical harmonics computed
  by LAL, across inclinations from face-on to face-off.
- **White-noise band.** O3 quotes the band by its lower edge and width;
  LALSimulation takes its centre, so the band is centred on $f_\text{low} +
  \Delta f / 2$. LALSimulation shapes the band and the time envelope smoothly,
  so the content is concentrated in, not confined to, $[f_\text{low},
  f_\text{low} + \Delta f]$.
- **White-noise duration and bandwidth.** LAL's `duration` and `bandwidth` are
  O3's $\tau_\text{WNB}$ and $\Delta f$. O3 injects the same white-noise set as
  the O2 search (Phys. Rev. D **104**, 122004, §IV A), and O2 generated its
  injections with Minke through LALSimulation (Phys. Rev. D **100**, 024017,
  arXiv:1905.03457, §III C). Minke's `WhiteNoiseBurst` (`minke/sources.py`,
  version 2.3.0) passes the burst group's $\tau$ and $\Delta f$ to LAL unchanged
  as `duration` and `bandwidth`, with the centre $f_\text{low} + \Delta f / 2$,
  as this package does. In LALSimulation's
  `XLALGenerateBandAndTimeLimitedWhiteNoiseBurst` (`LALSimBurst.c`), both are
  twice the standard deviation of a Gaussian amplitude envelope: the frequency
  envelope is $\exp[-2 (f - f_0)^2 / \Delta f^2]$, so $\sigma_f = \Delta f / 2$,
  and the time envelope's variance is set to $\sigma_t^2 = \tau^2 / 4 - 1 /
  (\pi^2 \Delta f^2)$ before the band is applied, so that the result has
  $\sigma_t = \tau / 2$. For a Gaussian amplitude envelope of standard deviation
  $\tau/2$ (and $\Delta f/2$), the power $h_+^2 + h_\times^2$ has RMS width (the
  square root of its power-weighted second moment) $\tau/(2\sqrt{2})$ (and
  $\Delta f/(2\sqrt{2})$). Averaged over 200 realisations (seeds 0–199) at 16384
  Hz with inclination 0 and $(\tau, f_0, \Delta f) = (0.1\ \text{s}, 150\
  \text{Hz}, 100\ \text{Hz})$, the power-weighted RMS widths are 0.0350 s in
  time and 35.3 Hz in frequency, against 0.0354 s and 35.4 Hz. The parameter
  docstring in `LALSimBurst.c` writes the envelopes with $\tau$ and $\Delta f$
  themselves as the standard deviation; the code and the function's detailed
  description use half of each.

## Relation to MDC-1

The specification follows the first Einstein Telescope mock data challenge
(MDC-1; T. Regimbau and J. Suresh, "A mock data challenge for next-generation
detectors", arXiv:2506.12237) wherever MDC-1 made a choice. **The MDC-1 data
release contains no burst injections**: its injection lists are compact-binary
lists only. What MDC-1 does carry is its frame generator's burst reader, which
fixes an event record and how numerical waveforms are placed. Those rows are
followed; for every other row MDC-1 has no precedent, and the choice is kept
from the LVK O3 all-sky search, or left open, for the reason given.

| Row                                  | MDC-1                                                                                                                                                                                           | This specification                                                                          | Reason                                                                                                                                                                                                                                                                          |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Event record                         | peak time, distance, right ascension, declination, polarization angle, inclination, model; the reader takes a bare distance and does not state its unit                                         | the same fields, under this package's names; distance in Mpc, this package's own convention | follows MDC-1 for the fields. The distance unit is not an MDC-1 precedent: MDC-1's unit is unverified, so Mpc is not claimed to match it                                                                                                                                        |
| Numerical waveform files             | columns $t$, $h_+$, $h_\times$, uniformly sampled, resampled to the data rate                                                                                                                   | the same                                                                                    | follows MDC-1                                                                                                                                                                                                                                                                   |
| Distance scaling                     | each model's strain scaled by its own reference distance over the event's                                                                                                                       | `reference_distance / distance`, with the reference distance set per file                   | follows MDC-1                                                                                                                                                                                                                                                                   |
| Inclination, axisymmetric model      | $h_+ \times \sin^2\iota$, $h_\times$ not injected                                                                                                                                               | `"axisymmetric"`, the same factors                                                          | follows MDC-1                                                                                                                                                                                                                                                                   |
| Inclination, bar-mode model          | $h_+ \times (1 + \cos^2\iota)/2$, $h_\times \times \cos 2\iota$                                                                                                                                 | `"rotating"`: $h_+ \times (1 + \cos^2\iota)/2$, $h_\times \times \cos\iota$                 | **Deviates.** $\cos\iota$ is the cross-polarization factor of a rotating ($m = \pm 2$) quadrupole, and is checked against the spin-weighted spherical harmonics. $\cos 2\iota$ is not: it would make an edge-on bar's $h_\times$ as large as its face-on one, where it vanishes |
| Inclination, f-mode models           | none                                                                                                                                                                                            | `"none"`                                                                                    | follows MDC-1                                                                                                                                                                                                                                                                   |
| Numerical waveform set               | the generator names an axisymmetric core-collapse model, a bar-mode model and f-mode models, but neither the generator nor the release includes their waveform files, and no burst was injected | none bundled                                                                                | **Open.** The set is MDC-1's kinds of model at most; the files are to be supplied by their owners, and are not substituted                                                                                                                                                      |
| Ad hoc families and their parameters | none                                                                                                                                                                                            | sine-Gaussian, Gaussian and white-noise burst, [above](#waveform-families)                  | MDC-1 has no ad hoc burst. The O3 all-sky set is a published, documented all-sky burst injection set, so its morphologies are kept rather than new ones invented; the sine-Gaussian $Q$ subset and $f_0$ draw are draft choices (open)                                          |
| Ad hoc polarization                  | none                                                                                                                                                                                            | elliptical, uniform in $\cos\iota$, as O3                                                   | MDC-1 has no precedent; kept from O3                                                                                                                                                                                                                                            |
| Strength                             | none: numerical models are set by distance                                                                                                                                                      | `hrss` log-uniform, as O3; range **open**                                                   | MDC-1 has no precedent for the distribution, kept from O3; it has no value for the range, which depends on the network's threshold                                                                                                                                              |
| Rate                                 | none: no burst was injected. The generator reads at most one burst per 2048 s frame segment, a limit of its layout rather than a chosen rate                                                    | fixed `interval`, **open**                                                                  | MDC-1 has no value, so none is set here                                                                                                                                                                                                                                         |
| Sky and polarization angle           | none                                                                                                                                                                                            | isotropic, $\psi$ uniform, as O3                                                            | MDC-1 has no precedent; kept from O3                                                                                                                                                                                                                                            |
| Test-set label                       | none                                                                                                                                                                                            | `injection_set="test"`                                                                      | the rate is a sensitivity choice, not an astrophysical one ([above](#test-set-not-population))                                                                                                                                                                                  |

## Open items

These rows of the specification are draft and are fixed per data set:

- the `hrss_range` and the injection `interval`, which MDC-1 does not set;
  [Choosing the strength range and the interval](#choosing-the-strength-range-and-the-interval)
  gives the convention;
- the sine-Gaussian frequency range and whether O3's gridded $f_0$ values are
  wanted instead of a log-uniform draw;
- whether circular sine-Gaussians are injected alongside elliptical ones;
- which numerical waveforms, at what distances and with which inclination
  dependence. MDC-1 names its kinds of model but provides no files.

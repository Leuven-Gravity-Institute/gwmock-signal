# Burst injections

A **burst** is a short gravitational-wave transient with no reliable template:
core-collapse supernovae, and anything else an unmodelled search is meant to
find. Searches for them are characterised by injecting a set of simple **ad
hoc** morphologies spanning the band and durations of interest, plus
**numerical** waveforms from simulations where they exist.

This page is both the user guide for `BurstSimulator` and the **specification of
the burst test injection set** it produces.

!!! warning "Status: draft"

    The injection set below is a draft. The families follow the LVK O3
    all-sky short-burst search; the values marked *open* in
    [Open items](#open-items) still need to be agreed for a given data set
    before an injection campaign is generated from it.

!!! tip "API reference"

    Signatures, types and raised exceptions are in the
    **[Burst API](../api/burst/)**.

## Quick example

```python
import numpy as np

from gwmock_signal import resolve_simulator_backend
from gwmock_signal.burst import draw_burst_injection_set

events = draw_burst_injection_set(
    start_time=1_000_000_000.0,
    end_time=1_000_086_400.0,  # one day
    interval=300.0,  # one injection every 300 s
    hrss_range=(1e-23, 1e-20),  # must straddle the network's threshold
    rng=np.random.default_rng(2026),
)

simulator = resolve_simulator_backend("burst")()
for event in events:
    strain = simulator.simulate(
        event,
        ["E1", "E2", "E3"],
        sampling_frequency=8192.0,
        minimum_frequency=5.0,
    )
```

`simulate` returns a `DetectorStrainStack` exactly as the compact-binary
simulator does, and accepts the same optional `background` mapping to inject
into existing data.

## Specification

### Event record

Each injection is one mapping. The keys correspond to the per-event record of
established burst injection pipelines — peak time, distance, sky position,
polarization angle, inclination and model — under this package's canonical
names, so a burst injection follows the same route as any other transient:
polarizations, then projection onto each detector, then injection.

| Key                  | Meaning                                                                       | Used by         |
| -------------------- | ----------------------------------------------------------------------------- | --------------- |
| `burst_model`        | morphology: `sine_gaussian`, `gaussian`, `white_noise_burst`, or a file model | all             |
| `peak_time`          | GPS time of the waveform's centre at the geocentre, s                         | all             |
| `right_ascension`    | rad                                                                           | all             |
| `declination`        | rad                                                                           | all             |
| `polarization_angle` | rad                                                                           | all             |
| `hrss`               | $\sqrt{\int (h_+^2 + h_\times^2)\,dt}$ at the Earth                           | ad hoc families |
| `inclination`        | rad; sets the polarization ellipse                                            | SG, WNB         |
| `frequency`          | central frequency $f_0$, Hz                                                   | SG              |
| `quality_factor`     | $Q$                                                                           | SG              |
| `duration`           | GA: standard deviation $\tau$ of $h_+(t)$; WNB: time envelope, s              | GA, WNB         |
| `low_frequency`      | lower edge of the band, Hz                                                    | WNB             |
| `bandwidth`          | width of the band, Hz                                                         | WNB             |
| `seed`               | integer fixing the noise realisation                                          | WNB             |
| `distance`           | source distance, Mpc                                                          | file models     |
| `injection_set`      | `"test"` for every event of the test set                                      | label, not used |

Keys a model does not use are ignored, which is what lets an event carry a
label.

### Waveform families

The ad hoc waveforms are generated by LALSimulation's burst routines, the ones
the LVK burst injections use, so their shapes and normalisation are LAL's. Every
family is normalised by `hrss`.

| Family                  | Draft parameters                                                                                 | Polarization                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| Sine-Gaussian (SG)      | $Q = 3, 9, 100$; $f_0$ log-uniform in 30–1800 Hz                                                 | elliptical, uniform in $\cos\iota$                                  |
| Gaussian pulse (GA)     | $\tau = 0.1$ ms, $2.5$ ms                                                                        | linear                                                              |
| White-noise burst (WNB) | $(f_\text{low}, \Delta f, \tau) = (100, 100, 0.1), (250, 100, 0.1), (750, 100, 0.1)$ (Hz, Hz, s) | elliptical, uniform in $\cos\iota$; one noise realisation per event |
| Numerical (e.g. CCSN)   | supplied as files; see [Numerical waveforms](#numerical-waveforms)                               | as in the file                                                      |

The Gaussian durations and white-noise parameters are those of the O3 all-sky
search (Phys. Rev. D **104**, 122004, Table I). The sine-Gaussian $Q$ values are
O3's; their central frequency is drawn instead of gridded, over 30–1800 Hz,
which keeps every $f_0$ far below the 4096 Hz Nyquist frequency of 8192 Hz data.
`DRAFT_BURST_FAMILIES` holds this table.

A source at inclination $\iota$ radiates $h_\times / h_+ = 2\cos\iota / (1 +
\cos^2\iota)$: circular when face-on, linear when edge-on. A circularly
polarized family, as O3 also used, is obtained by fixing `inclination` to `0` in
the family.

### Strength

`hrss` is drawn **log-uniform** over a range that must **straddle the detection
threshold** of the network under test, so that the efficiency curve is sampled
from where nothing is found to where everything is. The range has no default
because it depends on the detectors and the noise.

### Rate and placement

Injections are placed at a **fixed rate**, one per `interval` seconds, at
`start_time + (k + 1/2) * interval`. A spacing of a few hundred seconds keeps
the signals well separated — the longest draft waveform lasts about a second —
so each injection is recovered or missed on its own. Sky positions are
**isotropic** (uniform in right ascension and $\sin\delta$), and polarization
angles uniform in $[0, \pi)$.

### Test set, not population

The rate is chosen to measure a search's sensitivity, not drawn from any
astrophysical rate: a Galactic core-collapse rate would give essentially no
events in a month. Every event therefore carries `injection_set="test"`, and
results from it must not be read as an astrophysical population.

## Numerical waveforms

Numerical waveforms, such as three-dimensional core-collapse supernova
simulations, are supplied as text files with three whitespace-separated columns
— time (s, relative to the waveform's reference instant), $h_+$ and $h_\times$ —
at a common reference distance:

```python
from gwmock_signal.burst import BurstSimulator

simulator = BurstSimulator(
    waveform_files={"s18": "waveforms/s18.txt"},
    reference_distance=0.01,  # Mpc, i.e. the files are at 10 kpc
)
event = {
    "burst_model": "s18",
    "peak_time": 1_000_000_150.0,
    "distance": 0.005,  # 5 kpc
    "right_ascension": 1.0,
    "declination": -0.4,
    "polarization_angle": 0.3,
}
```

The file's time origin is placed at `peak_time`, the strain is scaled by
`reference_distance / distance`, and the waveform is resampled to the requested
rate if the file's differs. The file holds the strain for one viewing direction,
so no inclination is applied to it; a set covering several directions is several
files.

**No numerical waveforms are distributed with this package.** The loader is the
interface; the waveform files themselves come from their authors.

## Conventions and what they are checked against

- **Normalisation.** `hrss` is checked by computing $\sqrt{\sum (h_+^2 +
  h_\times^2)\,\Delta t}$ directly, independently of LAL, for every family.
- **Polarization ellipse.** The ratio $h_\times/h_+$ is checked against
  $2\cos\iota / (1 + \cos^2\iota)$ across inclinations, and the handedness flips
  for $\iota > \pi/2$.
- **White-noise band.** O3 quotes the band by its lower edge and width;
  LALSimulation takes its centre, so the band is centred on $f_\text{low} +
  \Delta f / 2$. LALSimulation shapes the band and the time envelope smoothly,
  so the content is concentrated in, not confined to, $[f_\text{low},
  f_\text{low} + \Delta f]$. Whether LAL's `duration` and `bandwidth` are
  exactly O3's $\tau_\text{WNB}$ and $\Delta f$ has not been checked against an
  independent reference.

## Open items

These rows of the specification are draft and are fixed per data set:

- the `hrss_range`, which depends on the network's detection threshold;
- the injection `interval`;
- the sine-Gaussian frequency range and whether O3's gridded $f_0$ values are
  wanted instead of a log-uniform draw;
- whether circular sine-Gaussians are injected alongside elliptical ones;
- which numerical waveforms, at what distances.
